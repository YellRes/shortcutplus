Under the Hood

工程师能欣赏的实现

The engineering behind the speed.
01

原生 FFI 直连 Win32

通过 koffi 现代 C FFI 直接调用 user32 / dwmapi 等系统 DLL，N-API 跨 Electron 版本 ABI 稳定，无需编译工具链。

02

同步枚举，无竞态

EnumWindows 配合注册回调同步构建窗口列表，过滤 DWM 隐藏窗口、工具窗口，解析末级弹窗祖先链——一次拿到真实 Alt+Tab 窗口。

03

中文标题精准解码

Win32 *A 接口在中文系统返回 GBK，读取原始字节后用 iconv-lite 解码，标题与进程名永不乱码。

04

轻量现代技术栈

Electron 19 + Vue 3 + TypeScript + Vite。无边框透明置顶覆盖层，进程图标按 exe 路径缓存，并行拉取互不阻塞。

FAQ

常见问题

Frequently asked questions.
AltSwitch 是什么？
AltSwitch 是一款 Windows 桌面应用，用来替代系统自带的 Alt+Tab 任务切换器。它枚举所有可切换的窗口，按所属进程分组，支持输入关键词即时筛选，并用键盘快速切换。
如何唤起 AltSwitch？
在任意界面按下 Alt + 4 即可唤起切换面板，面板会居中浮现并自动聚焦；失去焦点时自动隐藏。
支持哪些操作系统？
支持 Windows 10 和 Windows 11。这是一款仅限 Windows 的应用。
AltSwitch 收费吗？
免费。
它和系统自带的 Alt+Tab 有什么区别？
系统 Alt+Tab 在窗口很多时只是一长排缩略图，无法搜索、不分组；AltSwitch 提供 Spotlight 式命令面板，可即时搜索、按进程分组、纯键盘导航，并实时预览选中窗口的缩略图。
使用 AltSwitch 需要安装额外的运行时或编译环境吗？
不需要。原生 Windows 调用通过 koffi 完成并附带预编译二进制，安装时无需 Python 或 Visual C++ 工具链。
