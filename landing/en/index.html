Under the Hood

Engineering you can appreciate

01

Native FFI straight to Win32

Calls system DLLs like user32 / dwmapi directly via the koffi modern C FFI. N-API stays ABI-stable across Electron versions — no build toolchain needed.

02

Synchronous enumeration, no races

EnumWindows builds the list synchronously with a registered callback, filtering DWM-cloaked and tool windows and resolving the last-active-popup ancestor chain — real Alt+Tab windows in one pass.

03

Accurate CJK title decoding

Win32 *A APIs return GBK on Chinese systems; we read the raw bytes and decode with iconv-lite, so titles and process names never garble.

04

Lightweight modern stack

Electron 19 + Vue 3 + TypeScript + Vite. A frameless, transparent, always-on-top overlay; process icons cached by exe path and fetched in parallel.

FAQ

Frequently asked questions

What is ShortcutPlus?
ShortcutPlus is a Windows desktop app that replaces the built-in Alt+Tab task switcher. It enumerates every switchable window, groups them by owning process, lets you filter by typing a keyword, and switches with the keyboard.
How do I open ShortcutPlus?
Press Alt + 4 anywhere to summon the switcher. It appears centered and auto-focused, and hides automatically when it loses focus.
Which operating systems are supported?
Windows 10 and Windows 11. It is a Windows-only app.
Is ShortcutPlus free?
Yes, it is free.
How is it different from the built-in Alt+Tab?
The native Alt+Tab is just a long row of thumbnails when you have many windows, with no search and no grouping. ShortcutPlus gives you a Spotlight-style command palette with instant search, grouping by process, keyboard-only navigation, and a live thumbnail preview of the selected window.
Does ShortcutPlus need any extra runtime or build tools?
No. Native Windows calls go through koffi with prebuilt binaries, so installing needs no Python or Visual C++ toolchain.
